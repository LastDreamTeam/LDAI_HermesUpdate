# LDAI_HermesUpdate

**LD（LastDream · 最后的梦）舰队的 Hermes 维护与共享知识仓库。**

## 目标

参照 [LDAI_CodeStyleAgentSkill](https://github.com/LastDreamTeam/LDAI_CodeStyleAgentSkill) 的组织方式，后续建立适用于 LD 舰队的 Hermes 维护技能与新人入队规范，减少不同 Bot、不同服务器之间的知识断层与重复犯错。

计划统一整理各服务器维护者及 Bot 的有效经验，包括 Hermes 原生能力、日常维护、故障排查、协作习惯和真实验收方法。经验需有来源、经核实，再成为共同规范，而非直接复制某个 Bot 的整份记忆。

## 数据中心方向

采用 **GitHub＋传统自建数据库**：

- **GitHub**：管理可公开的技能、规范、通用模板及版本历史。
- **自建数据库**：承载跨服务器的私有知识索引、协作状态和核收记录；具体选型与实现后续确定。
- **各服务器**：保留各自的运行环境与隔离配置，不因知识共享而混用凭据、人格或核心记忆。

公开仓库不存放账号凭据、私密会话、核心记忆或内部服务器资料。

## 当前状态

**仅建立仓库与方向说明。**尚未发布实际技能、脚本或数据库实现，也未部署服务、迁移数据或替各 Bot 安装内容。

后续范围、实现方式与许可另行确定。
